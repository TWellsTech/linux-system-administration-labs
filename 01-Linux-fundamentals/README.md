# Linux System Administration Labs

**Maintained by:** TWellsTech

**Focus:** Linux System Administration | RHCSA Preparation | Security | Automation

## Project Overview

This repository documents my hands-on Linux system administration labs as I prepare for the Red Hat Certified System Administrator (RHCSA) certification and develop practical skills in enterprise Linux administration.

The objective is to demonstrate my ability to configure, manage, troubleshoot, and secure Linux systems through documented technical exercises.

## Technical Skills

- Linux command-line administration
- User and group management
- File permissions and access control
- SSH configuration and remote administration
- Networking and troubleshooting
- Storage and filesystem management
- System services and process management
- SELinux and firewall configuration
- Bash scripting and automation

## Lab Environment

Details of the operating system, virtualization platform, and lab architecture will be documented as the environment is configured.

## Lab Documentation

Each completed lab will include:

1. Objective and prerequisites
2. Commands and configuration steps
3. Screenshots or terminal output
4. Validation and testing
5. Troubleshooting and lessons learned
